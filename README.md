# Portfólio de Testes Manuais - QA

Este repositório armazena a documentação de testes manuais e relatórios de bugs criados durante meus estudos em Garantia de Qualidade (QA).

## 🛠️ Habilidades e Ferramentas

* **Testes Manuais:** Criação de Casos de Teste, Testes Negativos e Relatório de Bugs (*Bug Reporting*).
* **Controle de Versão (Git/GitHub):** 
  * Gerenciamento de repositórios remotos e locais.
  * Uso de comandos como `git add`, `git commit`, `git push`.
  * Organização de histórico de alterações e documentação em Markdown.
* **Metodologias:** Conceitos básicos de Ágil/Scrum.

## 📁 Projetos Inclusos
* Casos de teste funcionais e de login para o e-commerce [Sauce Demo](https://saucedemo.com).
